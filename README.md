# 🏆 Hackathon Organizing Portal

A complete **web-based platform** designed to simplify the process of organizing, managing, and participating in hackathons.  
This portal includes participant registration, project submission, result publishing, and a full admin management system.

---

## 🔗 Live Demo  
https://hophp.fwh.is/?i=1

---

## 🛠️ Technologies Used

- **Frontend**: HTML, CSS, JavaScript  
- **Backend**: PHP  
- **Database**: MySQL  
- **Environment**: XAMPP (Apache, MySQL, PHP)

---

## ✨ Features

### 👤 User Authentication
- Separate **Participant Login** and **Organizer Login**
- Secure authentication using PHP & MySQL
- Password validation and session-based login system

### 🏁 Hackathon Management
- Organizers can **create, edit, delete** hackathons  
- Add details like: Title, Description, Date, Rules  
- Participants can browse and register for hackathons

### 📥 Project Submission
- Participants can submit:
  - Project Title  
  - Project Description  
  - File Upload  
- Edit or update submissions before deadlines

### 🏅 Leaderboard & Results
- View hackathon results  
- Judges can assign scores

- 
### 🛠️ Admin Panel
- Admin dashboard for managing:
  - Users  
  - Hackathons  
  - Projects  
  - Scores  
  - Website content  

### 📄 Additional Features Added
- **Responsive UI** for mobile and desktop  
- **Multi-role system** (Admin, Organizer, Participant)  
- **Real-time updates** on hackathon deadlines  
- **Project gallery** for showcasing submissions  
- **Secure data handling** using prepared statements  

---

## 📥 Installation & Setup

1. Download or clone the project files.
2. Move the folder to your XAMPP `htdocs` directory.
3. Start **Apache** and **MySQL** from XAMPP Control Panel.
4. Import the SQL file into phpMyAdmin.
5. Update database credentials in the PHP config file.
6. Open the project in browser:  
   `http://localhost/your-folder-name/`
